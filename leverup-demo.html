ABOUT THIS BUILD

Small scope.
Visible evidence.

This is an independent proposal prototype by Laiba Nasir, built around nine selected LeverUp documentation pages reviewed on 22 October 2026.

What runs here
Lexical retrieval over reviewed summaries, linked source sections, conservative refusal, fee clarification, and a documented-source conflict case.
What this proves
You can inspect the sources and run the included baseline checks without an API key.
What comes next
The source package includes a FastAPI backend and an optional Claude adapter. Live model quality has not been tested. Full documentation ingestion and broader evaluation belong in the paid prototype.

This demo is not an official LeverUp product. It has no wallet connection, transaction execution, live prices, or account access.
